## Lobby / Testing Hero
- `-lvlup #` - (where "#" number from 1 to 30) Increases the hero's level
- `-gold #` - (where "#" number up to 99999) - Gives you gold
- `-respawn` - Resurrects the hero.
- `-refresh` - Removes cooldowns and gives full mana/full health.
- `-spawncreeps` - Create creeps.
- `-spawnneutrals` - Create neutral creeps.
- `-ping` - Shows the current ping (You can also use this command in a common game).
- `-teleport` - Teleports you to any point on the map (You need to show the point for teleportation with the cursor and then write this command in the chat).
